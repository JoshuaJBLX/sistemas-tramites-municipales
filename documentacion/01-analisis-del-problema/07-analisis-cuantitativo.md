## 7.2 Análisis de datos cuantitativos
- Alta demanda de orientación; fuerte base de conectividad móvil (91%) y poca oferta digital:
  oportunidad para un canal web ligero y móvil.

## 7.3 Conclusiones cuantitativas
- Justifican un asistente accesible desde móviles, con fuentes verificables.
- ❌ El sistema **no calcula estos indicadores**: no hay tablas de métricas ni endpoints (G-06/G-16).
- ✅ El catálogo implementado cubre 252 procedimientos TUPA 2023 (MPJ) — mayor cobertura que el
  universo citado en a.md.
